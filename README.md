# Zha Yuqi

Personal academic website of **Zha Yuqi** (also published as **Yuqi Zha**), a PhD candidate in Data Science at City University of Hong Kong.

**[Visit the live website →](https://charliez7.github.io/)**

My research focuses on sequential decision-making under uncertainty, including reinforcement learning, robust optimization, and robust and risk-aware Markov decision processes.

## Local preview

Install the Ruby dependencies:

```bash
bundle install
```

Start the local Jekyll server:

```bash
bundle exec jekyll serve
```

The website will be available at `http://localhost:4000`.

## Site structure

- `_pages/` contains the main website pages.
- `_publications/`, `_talks/`, and `_teaching/` contain academic entries.
- `_data/photos.yml` contains the photo gallery metadata.
- `images/` contains profile and gallery images.
- `_config.yml` contains site-wide settings and metadata.
